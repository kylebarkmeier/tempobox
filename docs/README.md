# TempoBox documentation

Start here.

- **[User guide](https://github.com/kylebarkmeier/tempobox/wiki)**: features and how to use the app,
  written for end users (install, library, playback, playlists, tags,
  Android Auto, settings, troubleshooting).
- **[Architecture](ARCHITECTURE.md)**: the concise decision record, with the
  module graph and the key design decisions in one page.
- **[Releasing](RELEASING.md)**: the operational guide for cutting a release
  (versioning, tagging, APK signing secrets).

Also useful: [`CLAUDE.md`](../CLAUDE.md) at the repo root is the condensed
contributor guiderails (hard rules + gotchas) that both humans and AI agents
follow when changing the code.
